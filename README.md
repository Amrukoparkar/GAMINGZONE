# 🎮 GAMINGZONE  

GAMINGZONE is a fun and interactive web-based project that offers a collection of classic online games. Designed for all age groups, it provides an engaging and user-friendly experience right from your browser.  

🌐 Live Demo: [GAMINGZONE](https://amrukoparkar.github.io/GAMINGZONE/)  

---

## ✨ Features  
- 🎲 **Tic-Tac-Toe** – A classic 2-player strategy game.  
- 🃏 **Flip the Card & Match the Pair** – Test your memory skills.  
- 🔢 **Guess the Number** – Challenge yourself to find the hidden number.  
- ⚡ Smooth, responsive, and easy-to-use interface.  
- 🧑‍🤝‍🧑 Suitable for all ages.  

---

## 🛠️ Tech Stack  
- **HTML5** – Structure  
- **CSS3** – Styling & Layout  
- **JavaScript (Vanilla JS)** – Game logic & interactivity  

---

## 🚀 How to Play  
1. Visit the live site: [GAMINGZONE](https://amrukoparkar.github.io/GAMINGZONE/)  
2. Select a game from the menu.  
3. Enjoy playing and challenge yourself!
